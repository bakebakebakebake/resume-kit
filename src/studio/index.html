    怎么用
    • 点简历上任何文字直接改，Tab / ⇧Tab 跳到下一个/上一个字段
    • 鼠标移到一块内容上，左边出现 + 和 ⠿：+ 在下面加一条，拖 ⠿ 换位置，单击 ⠿ 补字段、复制或删除
    • 在要点或技能行按 Enter 续写一条，清空后按 ⌫ 删掉这条；⌥↑ / ⌥↓ 移动当前行
    • 选中文字按 ⌘B 加粗、⌘E 标技术名、⌘K 加链接；悬停链接可以打开，⌘ 点击直接打开
    • 章节右边的小标签切换形态：经历 → 项目 → 清单 → 段落
    • 改完点保存，写回 resume.yaml，旧版本留在 .studio-backups/
